# Sample prompts for EduAdapt Studio

Copy any prompt, attach your own source files and adjust the details.

1. Extract the units and time budget from this syllabus and map them to a lesson plan.
2. Create a question paper from this blueprint, with a marking key.
3. Adapt this exam template to my course and keep its exact structure.
4. Write a rubric for this assignment aligned to the stated learning outcomes.
5. Audit my assessment inventory for coverage gaps and mark-total errors.
6. Prepare slides and notes for Unit 2, then run a content and format audit.

Tip: attach the official source (posting, syllabus, methodology or CV) and say the exact output format you want. The agent works best when it can cite what you provided.
