# EduAdapt Studio by Fahim

Open-source, portable educational content and assessment skill. This plugin contains **no fixed institutional, disciplinary, program, course, question-paper or mark-scheme assumptions**. Every production task begins with the user's own instruction, syllabus, requirements, and templates.

## How to use
1. Attach a governing syllabus or learning outline when available.
2. Attach the destination template, examination sample, board rules or rubric if fidelity matters.
3. State desired artifacts (such as lesson notes, slides, question paper, answers), learner level and language if not evident from the files.
4. Request a content and format audit before finalizing.

## Package contents
- `SKILL.md` and `AGENT_INSTRUCTIONS.md`: callable workflows and conduct.
- `references/`: eight focused workflow guides.
- `templates/`: optional starting structures and machine-readable schemas, explicitly **non-normative**.
- `scripts/`: independent Python 3 standard-library audits of user-defined assessments and delivery schedules.
- `examples/`: synthetic, subject-neutral inputs to test the scripts.
- `tests/`: regression tests for audit behavior.

## Important
The utilities audit a structured inventory *after* syllabus/template extraction and are not capable of confirming external regulation compliance on their own. A clean test report never certifies official examination approval. Scripts work offline and do not contact services.
