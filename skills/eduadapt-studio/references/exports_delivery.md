# Export and delivery verification
Deliver in formats explicitly requested or implied by the attached template. Where available, create editable DOCX/PPTX/XLSX versions and PDFs for final circulation when asked. Match template widths, margins, headers, table structure and typography when possible; inspect rendered pages/slides and fix overflow, broken tables, formulas and clipped content. Maintain version identifiers and a QA trail distinct from student copies. File names should be generic or user-provided rather than embedding an unrelated institution/course. For exams keep key and paper as separate artifacts. If one output depends on a workbook/answer key, reconcile question IDs and marks in both. Produce a concise summary of source coverage and unresolved conflicts, not a misleading claim of external validation.
