# Intake, evidence and source precedence
Identify goal and output first; treat an uploaded syllabus/template as authoritative task context rather than asking repetitive questions. Gather source name, edition, provenance and any conflicting instructions. Make an evidence ledger recording source file, page/tab/paragraph, extracted rule, interpretation and uncertainty. Resolve conflicts using user instruction, governing curriculum/regulation, specific output template and general source material in that order; do not violate a binding governing rule to imitate an outdated sample. Distinguish a sample's visual design from its legal or academic authority. If no syllabus is supplied, work from the stated topic/outcomes and clearly identify which constraints are not defined. Never silently insert institution name, marks, exam duration, accreditation code or author signature.
