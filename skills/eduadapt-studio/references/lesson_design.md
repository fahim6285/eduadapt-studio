# Teaching resources and lesson design
Map each syllabus scope item to measurable learning intentions, prerequisite review, explanations, worked examples, short checks, guided practice, independent practice, common errors, feedback and appropriate assessment. Respect user-specified learning level, course length, teaching periods, preferred methods and accessibility considerations. Allocate instruction time based on evidence or mark a proposed allocation as an assumption. Avoid redundancy and off-syllabus padding. Teaching notes may include definitions, derivations, examples, diagrams, formative questions and source references where relevant; format depends on learner context. Slides require readable text, a coherent visual sequence and speaker notes only when requested. Laboratories or practical work require safety constraints and a clear line between simulated and experimentally observed results.
