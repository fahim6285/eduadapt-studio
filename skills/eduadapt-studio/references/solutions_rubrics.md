# Solutions, marking keys and rubrics
Write model answers that can be checked against the exact question wording, including valid alternate solutions where applicable. Calculate all intermediate steps in quantitative questions, validate dimensions and units, and check final values. For qualitative answers, define expected evidence and points, not merely keywords. Rubrics should use user-defined criteria and performance bands when supplied; only propose neutral criteria if the rules permit. Individual mark allocations must sum to the advertised marks for that question. Explicitly distinguish student-facing papers from examiner-only keys. For questions with multiple correct interpretations, repair ambiguity rather than quietly selecting a favorite answer. Do not invent performance results, grades or exam approval.
